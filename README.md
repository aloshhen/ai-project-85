> 🤖 Этот проект был автоматически сгенерирован с помощью AI Constructor Bot

## 📝 Описание

создай лендинг для автоперевозок по РФ, хочу чтоьы ьылол стильно и много инофрмации включая тарифы, акции, о нас, контакты, крутые анимации с подстветкой, используй пресет Dark Matter

## 🚀 Технологии

- HTML5, CSS3 (SCSS), JavaScript  
- React (для интерактивных элементов и динамики)  
- Next.js (для SEO и SSR, если нужен быстрый рендеринг)  
- Framer Motion или GSAP (анимации)  
- Formik + Yup (форма обратной связи)  
- Leaflet.js (карта с маршрутами)
